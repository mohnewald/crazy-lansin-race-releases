# Carzy-Lansin-Race – Testversionen

Rallye-Shooter zu zweit: einer fährt, einer schießt. Alpha-Version für den Freundeskreis.

## Installieren

1. Unter [Releases](https://github.com/mohnewald/crazy-lansin-race-releases/releases/latest) die neueste
   `Carzy-Lansin-Race-Setup-<Version>.exe` herunterladen (Windows 10/11, 64 Bit, Grafikkarte mit Vulkan).
2. Ausführen. Windows warnt eventuell („Der Computer wurde durch Windows geschützt“), weil das Setup nicht signiert
   ist: auf **„Weitere Informationen“** und dann **„Trotzdem ausführen“** klicken. Adminrechte braucht es nicht.

## Zusammen spielen (LAN)

- Einer wählt im Startfenster **„Spiel hosten“**, die anderen **„Beitreten“** – das Spiel erscheint dort in der Liste.
- Beim ersten Hosten bzw. Beitreten fragt die Windows-Firewall: bitte **„Zulassen“** (privates Netzwerk).
- Nur gleiche Versionen spielen zusammen.

## Updates

Das Spiel prüft beim Start das neueste Release hier und bietet es im Startfenster an („Jetzt aktualisieren“).
